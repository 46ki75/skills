## Markdown Lint Analysis

### Content Analyzed

```markdown
Check out https://github.com/example/repo for more details.

Also see https://docs.example.com/guide
```

---

### MD034 — Bare URL Used

**Rule:** MD034 flags any bare URL in markdown — a URL that appears as plain text without being wrapped in angle brackets or formatted as a proper markdown link.

**Why it matters:** Most markdown renderers will auto-link bare URLs, but relying on this is inconsistent across tools and violates explicit markdown conventions. Wrapping URLs makes the intent clear and ensures reliable rendering.

---

### Issues Found in the Content

Both lines contain bare URLs that violate MD034:

1. Line 1: `https://github.com/example/repo` — bare URL
2. Line 3: `https://docs.example.com/guide` — bare URL

---

### How to Fix

**Option A — Wrap in angle brackets (inline link, URL as label):**

```markdown
Check out <https://github.com/example/repo> for more details.

Also see <https://docs.example.com/guide>
```

**Option B — Use a proper markdown link with descriptive text:**

```markdown
Check out [example/repo](https://github.com/example/repo) for more details.

Also see the [guide](https://docs.example.com/guide)
```

Option B is preferred when meaningful link text can be provided, as it improves readability and accessibility.
