## What is MD034?

**Rule**: MD034 — `no-bare-urls`

**What it does**: MD034 flags any URL that appears "bare" in the markdown text —
meaning it is written as a plain URL without being wrapped in angle brackets `<>`
or formatted as a proper markdown link `[text](url)`.

Markdown renderers may or may not auto-link bare URLs depending on the parser.
To guarantee a URL is rendered as a clickable hyperlink consistently across all
Markdown renderers, it must be explicitly wrapped.

## Why MD034 Triggers

Both URLs in the content are bare:
- `https://github.com/example/repo`   → bare URL (no wrapping)
- `https://docs.example.com/guide`    → bare URL (no wrapping)

## How to Fix MD034

There are two valid approaches:

### Option 1 — Wrap in angle brackets (inline link, URL as display text)
```markdown
Check out <https://github.com/example/repo> for more details.

Also see <https://docs.example.com/guide>
```

### Option 2 — Use a named markdown link (preferred for readability)
```markdown
Check out [example/repo](https://github.com/example/repo) for more details.

Also see [the guide](https://docs.example.com/guide)
```
