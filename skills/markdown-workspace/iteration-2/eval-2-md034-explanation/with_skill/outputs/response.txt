### What is MD034?

**MD034 — No bare URLs** (`no-bare-urls`)

MD034 flags any URL that appears "naked" (bare) in the body of a Markdown
document — meaning a raw URL written out as plain text without being wrapped
in angle brackets (`<…>`) or formatted as a proper Markdown hyperlink
(`[link text](url)`).

Markdown renderers behave inconsistently with bare URLs:
- Some auto-link them (GitHub Flavored Markdown does).
- Others render them as plain, non-clickable text.

By requiring explicit link syntax, MD034 ensures:
1. **Consistent rendering** across all Markdown processors.
2. **Accessible link text** — screen readers and users see meaningful labels
   instead of raw URL strings.
3. **Readability** — long URLs don't clutter prose.

---

### How to Fix MD034

There are two accepted fix patterns:

#### Option A — Angle-bracket wrapping (auto-link)

Encloses the URL in `<` and `>`. The URL itself becomes the link text.

```markdown
Check out <https://github.com/example/repo> for more details.

Also see <https://docs.example.com/guide>
```

#### Option B — Descriptive Markdown link (recommended for readability)

Provides a human-friendly label, which is better for accessibility.

```markdown
Check out the [example repository](https://github.com/example/repo) for more details.

Also see the [example guide](https://docs.example.com/guide)
```
